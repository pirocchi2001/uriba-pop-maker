# インスパイア型 売場POPメーカー（試作）

商品名・公式ページ・キーワード・商品画像の色から、公式デザインを真似しない「オリジナルテーマ」を作り、売場POP一式（トップボード、サイドパネル、下段装飾、カードレール、完成図）を印刷用JPEGでZIPに書き出します。

- テーマの作り方：ローカル（AIなし）／Gemini（無料枠・ページを読む）／OpenRouter（無料モデル）
- APIキーはブラウザの中だけで使います（「この端末に保存する」を選んだときだけ端末に保存）
- フォント：M PLUS Rounded 1c Black、Noto Sans JP Black（SIL Open Font License、JIS第1・第2水準にサブセット）
- ライブラリ：opentype.js（MIT）、JSZip（MIT）

GitHub Pages で `index.html` を開いて使います。
